# Mécanismes animés

Mécanismes de chimie organique de PCSI et de PC, animés pas à pas (flèches courbes, profil énergétique, mode quiz), et corrigés des atlas d'entraînement d'orga.

Page en ligne : https://benjaminbousquet.github.io/Orga/

- `index.html` : la page (mécanismes dans l'objet `MECHS`, classement par chapitre dans `META`).
- `atlas/` : corrigés d'atlas convertis par `Cours et TD/_scripts/atlas_web.py`.
- Un mécanisme s'ouvre directement avec `#clé` (par exemple `#sn2`), un atlas avec `#atlas-pcsi9`.
